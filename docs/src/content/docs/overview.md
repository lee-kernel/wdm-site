WDM 将日常记录、可复用资产与自动执行连接成一条工作流。

| 功能 | 可以实现什么 | 适合什么时候用 |
| --- | --- | --- |
| 工作报告 | 编写日报；从目标周的已保存日报生成周报 | 记录进展、复盘一周工作 |
| 提示词库 | 保存文本正文、变量和默认值，预览、优化与复制 | 重复使用稳定的 AI 指令 |
| 脚本库 | 保存、查看、分析、下载和测试脚本 | 沉淀可重复执行的处理逻辑 |
| 避坑智库 | 保存问题、原因、权衡和解决方案，支持 Markdown 与 AI 优化 | 沉淀可复用的排错经验 |
| 分享码 | 预览内容快照，领取为自己的私有副本 | 向其他账号传递提示词、脚本和经验 |
| 标签 | 用私有键值标签组织提示词、脚本、任务和经验 | 跨资产建立统一筛选维度 |
| 自动任务 | 按计划或 Webhook 执行 AI 任务与脚本 | 自动处理重复且规则清晰的工作 |
| 通知渠道 | 通过邮件或 Bark 发送自动任务结果 | 不打开工作台也需要收到结果 |
| 账号与权限 | 密码或 Passkey 登录，按用户组获得菜单与能力 | 保护账号并控制功能范围 |
| 数据备份 | 本人业务数据快照、ZIP 导出与覆盖还原 | 重要修改前留存恢复点 |

| 反复使用同一套 AI 指令 | [提示词库](../guides/prompts/) | 变量替换后的正文可复制 |

## AI 能力如何工作

工作报告整理、提示词优化、脚本解释与安全分析，以及自动任务中的 AI 执行，都由外部 Hermes-Agent 提供。WDM 保存报告、提示词、脚本和任务等业务数据，通过 OpenAI 兼容接口提交当前任务所需内容，再接收最终文本或 JSON 结果。

模型与 Provider、会话历史、记忆、Skill、Tool 和 Agent Loop 由 Hermes-Agent 管理。WDM 每次请求按独立上下文提交，不自动附带历史；外部服务的实际隔离行为取决于其配置。需要连续参考时，在当前任务提供完整材料，或关联上游输出。

Hermes-Agent 的连接地址、访问密钥、模型和超时由管理员在系统配置中维护。未完成配置或服务不可用时，普通记录与资产管理仍可使用，但依赖 AI 的操作会失败。

## 推荐工作方式

```text
记录真实进展 → 找到重复方法 → 保存提示词或脚本 → 手动验证 → 自动执行 → 检查日志
```

自动化不是起点。输入还在频繁变化、结果难以判断时，先保留人工步骤通常更合适。
