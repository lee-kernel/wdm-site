---
title: 功能总览
description: 了解 WDM 各项功能之间的关系和适用场景。
---

WDM 将日常记录、可复用资产与自动执行连接成一条工作流。

| 功能 | 可以实现什么 | 适合什么时候用 |
| --- | --- | --- |
| 工作报告 | 编写日报；从目标周的已保存日报生成周报 | 记录进展、复盘一周工作 |
| 提示词库 | 保存文本或结构化提示词，分类、打标签、优化与复制 | 重复使用稳定的 AI 指令 |
| 脚本库 | 保存、查看、分析、下载和测试脚本 | 沉淀可重复执行的处理逻辑 |
| 标签 | 用私有的 `键 + 值` 标签组织提示词、脚本和自动任务 | 跨不同资产建立统一筛选维度 |
| 自动任务 | 按计划或 Webhook 执行 AI 任务与脚本 | 自动处理重复且规则清晰的工作 |
| 通知渠道 | 通过邮件或 Bark 发送自动任务结果 | 不打开工作台也需要收到结果 |
| 账号与权限 | 密码或 Passkey 登录，按用户组获得菜单与能力 | 保护账号并控制功能范围 |

## 推荐工作方式

```text
记录真实进展 → 找到重复方法 → 保存提示词或脚本 → 手动验证 → 自动执行 → 检查日志
```

自动化不是起点。输入还在频繁变化、结果难以判断时，先保留人工步骤通常更合适。
