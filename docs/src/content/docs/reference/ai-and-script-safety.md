title: AI 与脚本安全
description: 在使用 AI、脚本和自动任务时保持结果可控。
---

## AI 输出需要确认

工作报告整理、提示词优化、脚本解释和安全分析都属于辅助能力。AI 返回成功不代表内容事实正确，也不代表脚本安全。

- 报告候选内容保存前检查事实、日期和敏感信息。
- 提示词优化后用代表性输入重新测试。
- Webhook 载荷和上游任务输出都按不可信材料处理。

## 脚本执行边界

Python、JavaScript 和 Shell 通过隔离执行服务运行，并受到请求大小、源码、输入、输出、时间、内存和进程数量限制。PowerShell、SQL 和其他语言只能保存与查看。

隔离能降低风险，但不能替代脚本审查：

1. 不在源码和参数中保存密钥。
2. 明确约定标准输入与标准输出格式。
3. 对错误输入和超时设计可理解的失败信息。
4. 在线测试通过后再加入自动任务。
5. 修改已关联脚本后重新测试。

## 自动化会放大影响

会发送消息、调用外部服务或修改数据的任务，应先用测试对象完整跑通。优先从单次任务开始，确认执行日志和通知结果后，再改为周期或 Webhook 触发。
