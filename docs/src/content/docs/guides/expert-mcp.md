---
title: 专家名片与 MCP 接入
description: 维护账号的专家名片，并授权可信 Agent 访问支持的能力。
---

WDM 的每个账号可以维护自己的专家名片，描述领域、擅长的问题和工作方式。通过 MCP 授权，兼容的 Agent 可以读取该名片，并按授权使用该账号已有的资产工具。

## 1. 维护专家名片

登录工作台，进入“账户中心 → 专家名片”，填写名称、简介、领域、擅长问题、不覆盖范围和工作说明，然后保存。字段可以留空；写清适用范围有助于 Agent 判断何时查询。

名片对应一个稳定的专家标识，更新名片不会改变该标识。名片是对专家的说明，本身并不代表独立知识库检索或操作授权已经具备。

## 2. 创建 MCP 授权

1. 进入“账户中心 → MCP 授权”，选择“创建授权”。
2. 设置授权名称、有效期和所需范围。要读取专家名片，选择“读取专家名片”；要查询经验，还需单独授予避坑智库的读取范围。提示词、脚本和标签也有各自的范围。
3. 创建后复制接入提示词，并仅发送给可信的客户端。提示词包含令牌，明文只展示一次；关闭后无法再次查看，丢失时应撤销或删除原授权并重新创建。聊天记录也可能保存令牌。
4. 按客户端版本配置远程 MCP 与 Bearer 认证，检查工具列表，再用只读方式读取专家名片，核对返回的专家标识。

授权范围受当前账号的功能权限限制；写入和编辑范围可能允许客户端修改数据，只授予可信客户端。修改有效授权范围时必须包含“读取专家名片”；旧授权不会自动获得这个范围。撤销、删除或过期后，新请求不再有效，已通过认证的请求不保证中止。

## 3. 让 Agent 使用资料

按授权范围，Agent 可以查询本人避坑经验、提示词和脚本等已有资产。提示词和脚本的推荐使用关键词匹配，结果应由用户选择；MCP 不提供脚本执行工具。名片与资产正文不构成执行脚本、发送消息或更改外部数据的授权。

同一个 Agent 可以尝试配置多个账号的连接，每个连接使用对应账号的令牌。客户端是否支持区分同地址的多个连接、是否加载接入提示词中提供的 Skill，以及是否会主动选择专家，取决于客户端和实际配置，应逐一验证，避免覆盖已有连接。

独立知识库、统一专家检索与多专家自动路由仍在建设规划中，不应假定当前已经实现。

## 常见问题

- **找不到入口或授权范围：** 请管理员检查当前账号的专家名片及对应业务功能权限。
- **授权后看不到工具：** 检查令牌范围和当前功能权限，必要时重新加载工具列表或重新连接。
- **连接错误账号：** 读取专家名片并核对专家标识；确认连接配置与令牌对应。
- **令牌泄露：** 尽快在 MCP 授权页面撤销或删除，再为可信客户端重新创建。
