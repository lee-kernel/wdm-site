进入 **工作报告中心**，保存每天进展，并汇总为周报。每位用户在同一个日期只能保存一篇日报，在同一个 ISO 周只能保存一篇周报。

## 先整理输入材料

按“事项、进展、结果、问题、下一步”记录事实即可。例如下面是演示材料，不对应真实业务：

```text
完成：核对使用说明，修正两处过时步骤。
进行中：为快速开始补充截图，尚有一张待核对。
问题：暂未验证手机端排版。
下一步：检查窄屏阅读效果，再提交更新。
```

数字、时间、完成状态和待确认事项都应来自真实记录。AI 可以改善表达，不应把“进行中”改写为“已完成”。

## 编写日报

1. 选择“日报”和报告日期。
2. 输入当天的原始记录。
3. 可选使用整理、润色、扩写、精简、正式化或校对等 AI 动作。
4. 检查 AI 返回的候选内容。
5. 确认内容后保存，并按需要设为草稿、已完成或已归档。

AI 处理不会直接覆盖已有报告。原始内容和最终内容可以同时保留，方便回顾修改过程。

![新建日报页面，左侧填写原始工作记录，右侧检查和编辑日报成稿](../../../assets/screenshots/report-editor.png)

_新建日报时先在左侧记录事实；使用 AI 整理后，在右侧检查并编辑成稿，再决定是否保存。_

## 生成周报

1. 确认目标周内的日报已经保存。
2. 选择年份和 ISO 周次。
3. 决定是否包含下周计划，并按需补充指令。
4. 生成周报，核对来源日报、事实与表达。
5. 确认后保存。

目标周没有日报时，系统不会生成周报。

ISO 周从周一开始，在年末年初可能与自然年边界不同。缺少来源时先核对年份、周次和日报日期，确认日报已经保存，而不只是停留在编辑器中。

## 找回与维护报告

在列表中切换日报、周报，结合关键词、日期和状态筛选。打开报告后可以继续编辑或调整状态。

| 状态 | 建议使用方式 |
| --- | --- |
| 草稿 | 内容还在补充或等待核对 |
| 已完成 | 已确认本次要保留的正文 |
| 已归档 | 留作历史记录和复盘 |

状态不改变周期唯一性或归属。重复周期保存时先检查已有报告，再决定是否明确覆盖。

## 常见情况

| 情况 | 处理方法 |
| --- | --- |
| AI 整理失败或结果为空 | 保留原始材料，稍后重试或手动编辑 |
| 成稿出现未提供的成果 | 删除推测，重新约束整理要求 |
| 周报来源数量与详情不一致 | 来源日报可能已删除，检查仍存在的日报 |
| 日期或报告类型选错 | 保存后不能改周期，确认处理方式后重新创建 |

## 注意事项

- 报告保存后不能更改类型或所属日期、周次。
- 同周期已有报告时，必须明确确认覆盖；系统不会静默覆盖。
- 周报来自目标周内当前账号已保存的日报，不会读取其他用户的内容。
- 删除日报可能影响既有周报的来源摘要展示。
- `AI 已处理` 只表示内容使用过 AI，不代表事实已经审核。
- 当前不支持月报和自定义报告模板。
