## WDM 可以帮你完成什么

<CardGrid>
  <Card title="写日报与周报" icon="document">
    记录每天的工作进展，并从已经保存的日报生成周报。AI 可以辅助整理，但保存前始终由你确认。
  </Card>
  <Card title="管理提示词与脚本" icon="puzzle">
    保存已经验证有效的方法，通过分类和标签快速找到、复用或继续优化。
  </Card>
  <Card title="自动执行重复工作" icon="setting">
    按时间计划或 Webhook 事件运行 AI 任务与脚本，并查看每一次执行结果。
  </Card>
  <Card title="把结果发送给自己" icon="email">
    通过邮件或 Bark 接收任务结果。渠道配置保持独立，更新后会在下次任务执行时生效。
  </Card>
</CardGrid>

WDM 适合将“经常做、过程稳定、结果可检查”的工作逐步沉淀下来。第一次使用时，建议从[写一篇日报](./guides/reports/)开始。
