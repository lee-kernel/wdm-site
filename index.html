开始之前

你可能还想了解

Mori 自带 AI 模型吗？+

Mori 通过外部 Hermes-Agent 调用 AI 能力。模型、会话历史、工具与 Agent Loop 由 Hermes-Agent 管理，连接信息在系统配置中维护。

报告和提示词会自动公开吗？+

不会。报告、提示词、脚本、经验和知识按账号隔离。发布知识文章后，本账号获授权的 Agent 才能查询。

可以自行部署吗？+

项目使用 Docker Compose 组织 Web、API、Worker、PostgreSQL 和脚本执行器。部署前需完成环境变量、数据库挂载、外部网络与 Nginx 证书配置；AI 功能还需连接 Hermes-Agent。
